# Gemini 4 Argon — примеры фронтенд-дизайна

Два HTML-демо, предоставленные автором как результаты Gemini 4 Argon. Исходные файлы опубликованы без изменений.

- [Liquid Glass](liquid_glass_ui.html)
- [Веб-дизайн 2026](2026.html)

## Исходные промпты

### Liquid Glass

Сделай демо-страницу дизайна liquid glass. Где уместно, используй «ручки», чтобы показать варианты.

### Веб-дизайн 2026

Используй веб-поиск и разберись, какие сейчас стили популярны в веб-дизайне. Затем собери html-сайт с презентацией этих стилей: переключатель между стилями, для каждого стиля страница с рассказом о нем и интерактивным элементом (или элементами), демонстрирующими его особенности. Также расскажи, когда стоит применять, когда - нет.

## Публикация

Статические файлы; сборка не требуется. GitHub Pages: Deploy from a branch → main → / (root).

Внешние зависимости: Tailwind CDN, Google Fonts, Lucide (энциклопедия), Phosphor Icons (Liquid Glass).
